# SASRec attribution

The ArtMatch recommendation code in this folder is an adapted local implementation
based on the SASRec architecture and informed by pmixer/SASRec.pytorch.

Reference implementation: pmixer/SASRec.pytorch
License: Apache License 2.0

Original paper:
Wang-Cheng Kang and Julian McAuley,
"Self-Attentive Sequential Recommendation," ICDM 2018.

This ArtMatch adaptation is not a verbatim copy of the upstream Python files.
